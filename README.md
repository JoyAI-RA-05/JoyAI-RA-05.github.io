# JoyAI-RA 0.5 project page

This repository is a dependency-free static website. The page consists of
`index.html`, `styles.css`, `app.js`, and the files under `assets/`.

## Preview locally

```bash
cd /Users/liwenhao.109/projects/claude_code/github_pages/JoyAI-RA-05.github.io
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Stop the server with `Control-C`.

No package installation, build command, database, or external deployment is
required.
